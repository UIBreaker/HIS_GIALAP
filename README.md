# Giả lập đăng ký khám chữa bệnh HIS

[![Chạy trực tiếp](https://img.shields.io/badge/Ch%E1%BA%A1y%20tr%E1%BB%B1c%20ti%E1%BA%BFp-M%E1%BB%9F%20%E1%BB%A9ng%20d%E1%BB%A5ng-blue?style=for-the-badge)](https://uibreaker.github.io/HIS_GIALAP/)

Ứng dụng giả lập đăng ký khám chữa bệnh, quét CCCD giả lập và quản lý hồ sơ ngay trong trình duyệt. Dữ liệu được lưu cục bộ bằng localStorage; có thể tìm kiếm, xem chi tiết, sửa, xóa và xuất JSON hoặc CSV.

## Chạy trên máy

Mở `ban-chay-truc-tiep.html` trong Chrome, Edge hoặc Firefox. Bạn cũng có thể mở `index.html` khi `app.js` và `style.css` nằm cùng thư mục.

Chỉ sử dụng dữ liệu giả lập; không nhập thông tin bệnh nhân hoặc giấy tờ thật.
